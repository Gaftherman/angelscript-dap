## [1.0.0] - 2026-11-25

### Added

- First release as its own repository. The host-agnostic Debug Adapter Protocol core moves here from the Sven Co-op plugin, and the AngelScript CLI, the example project and the plugin build it as a submodule.
- The `angelscript_dap` target, with `asdebugger_core` kept as the library's earlier name.
- `ASDEBUGGER_CORE_COMPILE_OPTIONS` for embedders that need flags such as `-m32`.
- English and Spanish documentation, support and contribution guides.
